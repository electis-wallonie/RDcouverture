# RD Couverture

Site web de RD Couverture, entreprise familiale de couverture à Saint-Gilles, près de Saint-Lô (Manche).

Le site est mis en ligne automatiquement avec GitHub Pages à chaque modification du dossier site-web : https://electis-wallonie.github.io/RDcouverture/

Organisation : le dossier site-web contient la page (index.html), les styles (css), les icônes (js) et les photos de chantier (images). Le fichier .github/workflows/deploy.yml gère la mise en ligne.

## À compléter

- Formulaire de devis : renseigner `WEB3FORMS_KEY` dans site-web/index.html avec une clé Web3Forms créée pour rdcouverture.contact@gmail.com.
- Pixel Meta (facultatif) : renseigner `PIXEL_ID`. Tant qu'il est vide, aucun pixel ni bandeau cookies n'est affiché.
- Le logo (images/logo-rd-couverture.svg) est redessiné d'après le marquage du véhicule ; à remplacer par le fichier d'origine si le client l'a.
